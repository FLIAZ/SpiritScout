# 会话流量记录与协议分析

会话内选择「流量」，或从主页左侧进入「流量」。主页左侧按项目分类（含全部项目和未分类），
右侧显示各会话的交互记录、错误与正文大小，点击会话后查看其任务交互。
流量页只展示任务交互；点击记录后，该行高亮并标出序号，与下方详情对应。
离线数据包只在附件查看器中展示，不在流量页嵌入采集、导入或数据包切换。

## 应用交互

内置 `http_probe` 自动记录 HTTP/HTTPS，每次重定向单独一条，连接失败也留记录；
`dns_resolve` 记录系统解析结果，`tcp_scan` 记录逐端口连接结果和已读取的服务横幅。
系统解析可能命中 hosts/缓存，不能据此声称发送过 DNS 包；TCP 横幅仅为工具已读取的片段。
这些记录不改变工具的请求方式、目标范围、重试、下载上限或审批语义。

支持地址/方法的字面量筛选、仅看失败或 HTTP 4xx/5xx、游标分页、详情和手动刷新。
最新页每五秒自动刷新，旧页及隐藏页面不轮询记录；慢请求期间不叠加自动刷新请求。
缺失的 Agent、任务或调用归属留空，不按目标地址猜测发起者。
历史会话不补采，也不自动重放请求。

应用交互副本保存在会话 `traffic/records.db`，与黑板、审计及已有 `http-responses/` 原文快照分开。
每个方向的正文预览上限为 32 KiB；二进制使用 Base64 展示。
JSON/表单先脱敏再截断，超过上限或无法安全解析时直接省略。
常见认证参数、Cookie/Set-Cookie、Authorization、API Key 和 JSON/表单敏感字段被隐藏；
其他正文仍可能包含业务数据，不能视为全面脱敏。原有 HTTP 快照保存行为不变。
HTTP 响应体为解压后已读取内容，重定向响应体沿用原工具行为不下载。
「预览截断」与「响应体未完整采集」分别标记；统计正文大小不是 TCP/TLS 线上字节数。
采集写入失败只留本机警告，不使工具重试目标。

## 离线流量附件查看器

上传 `.pcap`、`.pcapng` 或 `.cap` 附件后，不自动弹出预览。消息气泡内的附件卡片
提示可放大查看，点击「查看数据包」才打开并解析；历史附件也可从卡片再次查看。
附件依据真实文件头校验，不能仅通过改扩展名伪装流量包。
打开时自动交给本机 tshark 解析，不发起目标网络请求，不改写附件原件。
重复打开内容相同的附件复用会话内解析索引，不重复生成抓包记录。

界面采用 Wireshark 式三窗格：

- 上方按原始包序排列时间线，展示包编号、微秒精度相对时间、源/目标地址和端口、协议、
  帧长度及协议摘要；从第一个包开始分页，支持 Wireshark 显示过滤器。
- 默认查看第一页首包，点击整行或编号可切换，当前包持续高亮；详情标题标明包序号。
- 下方展示 tshark 解析出的 Frame、Ethernet、IP/IPv6、TCP/UDP 和应用协议字段。
  HTTP、DNS、WebSocket 等应用层默认展开，不仅展示 IP 地址。
- 负载区展示传输层正文文本及原始 Hex/ASCII，可直接看到明文 HTTP 请求行、头部及已捕获内容。
  TCP/UDP 流追踪由 tshark 重组，支持双向文本和 Hex 切换，重传由解析器处理。
- 附件和原始数据包未脱敏，内容仅作为文本显示，不执行捕获的 HTML/脚本。

离线预览需要已安装 tshark，无需抓包权限。文件上限 20 MiB，每个附件最多解析 10,000 包，
原始帧预览最多 64 KiB、负载预览最多 8 KiB，流显示最多 128 KiB / 500 段。
达到解析上限、字段省略、字节截断和失败状态都会显示；原文件可下载交给完整 Wireshark。
关闭查看器停止前端轮询，后台解析仍归应用生命周期管理；删除会话会回收解析任务。

HTTPS、TLS、WSS、QUIC 通常仍是密文；文本负载视图不等于解密，也不会自动安装证书。
此查看器未实现完整 Wireshark 的全部分析器、图表、逐字段字节高亮和解密配置。
原有采集 API 保留兼容，但前端不再提供实时采集入口。

## 只读查询与采集接口

接口沿用控制台认证，流量响应与下载使用 `Cache-Control: no-store`。

- `POST /api/sessions/{session_id}/artifacts/packets?path=attachments/example.pcap`：自动解析已有附件并返回索引；不发起目标请求。
- `GET /api/traffic`：项目及会话汇总；不可读会话标记 `available=false`。
- `GET /api/sessions/{session_id}/traffic`：应用交互列表，支持 `before`、`limit`（1–100）、`query`、`errors_only`。
- `GET /api/sessions/{session_id}/traffic/{record_id}`：应用交互详情。
- `GET /api/traffic/capabilities`：tshark 可用性、实时采集状态、网卡及存储上限。
- `GET /api/sessions/{session_id}/traffic/captures`：抓包文件及解析/采集状态。
- `POST /api/sessions/{session_id}/traffic/capture`：JSON `interface`、`capture_filter`、`duration`，启动采集。
- `DELETE /api/sessions/{session_id}/traffic/capture`：停止本会话采集或解析，不删除证据。
- `POST /api/sessions/{session_id}/traffic/capture/import?name=capture.pcap`：请求体为原始文件字节，流式接收。
- `GET /api/sessions/{session_id}/traffic/packets`：指定 `capture_id`，可传 `before`、`limit`（1–200）、`display_filter`。
- `GET /api/sessions/{session_id}/traffic/packets/{packet_id}`：协议树和原始字节预览。
- `GET /api/sessions/{session_id}/traffic/captures/{capture_id}/follow?protocol=tcp&stream=0`：TCP/UDP 流追踪。
- `GET /api/sessions/{session_id}/traffic/captures/{capture_id}/download`：导出原始 PCAP/PCAPNG。

应用交互和数据包的编号都在会话内查找，不能用另一会话的引用读取证据。
项目重分配只改变归类，删除项目后保留会话流量并归入未分类；删除会话时随目录删除。

## Linux 会话代理录制

参考 ARTEX 的应用层代理思路，灵枢增加可选的 Go 代理进程，Python 继续负责会话生命周期、
SQLite 索引和证据接口。代理与原有工具记录、tshark 数据包分析并存。
本次实现面向 Linux 原生运行；没有增加 Windows、macOS 或 Docker 的接入配置。

### 构建与启用

在项目根目录使用 Go 1.26 或更高版本运行：

```bash
./scripts/build-traffic-proxy.sh
```

程序输出到已忽略的 `.tools/spiritscout-traffic-proxy`，也可通过
`SPIRITSCOUT_TRAFFIC_PROXY` 指定可执行文件路径。没有该程序时，工具原有行为保持可用，
页面提示代理不可用。构建不会安装系统服务、证书或修改全局 Go 配置。

新增 Python 接口需要后端重启后加载。如果页面提示「当前后端未提供代理功能」，
请在运行任务结束后重启服务并刷新页面；普通流量记录不依赖此可选代理。

进入会话的「流量 → 应用交互」，展开默认折叠的「可选：录制命令流量」，点击「启用代理录制」。可在启用前填写 HTTP、HTTPS 或
SOCKS5 上游出口代理。代理仅监听随机回环端口，以每会话独立口令认证。
新启动的 Linux 沙箱命令和本地执行器自动获得代理环境与会话 CA；已运行的进程、
忽略代理环境的程序、远程 MCP、直接 TCP/UDP 和容器内程序不因此自动录制。
内置 `http_probe` 沿用自己的记录通道。手动接入配置包含代理口令，应按凭据保管。

HTTPS/WSS 通过会话 CA 介入 TLS 握手，不安装系统 CA，不关闭上游证书验证。
目标使用私有 CA 时，需要让服务进程已有的可信根配置（例如 `SSL_CERT_FILE`）包含它。
CA 私钥仅存在 Go 进程内存中；沙箱仅只读挂载公有 CA 证书目录，不能访问流量数据库、
原文存储或代理控制目录。代理认证信息不会作为目标请求头转发。
证书固定、独立证书库或自定义代理实现可能不兼容这种录制方式。

离开页面不停止代理。手动停止、删除会话、服务正常关闭及父进程控制管道断开时回收代理；
停止会结束经过代理的活动连接。服务重启后默认关闭，历史证据保留。
代理异常会显示错误；后续新工具不再注入该代理，已失败的目标请求不会自动重放。

### 原文、搜索与工具复用

请求、响应流式转发并保存原文，每个方向最多保存 32 MiB，超过时仅停止保存副本，
继续转发目标流量。记录区分实际传输量、已保存量、完整性和采集错误。
正文按 SHA-256 存入会话 `traffic/blobs/` 去重，原始头部和归属索引保存在 SQLite。
原文下载和按字节读取**未脱敏**；页面普通详情和搜索使用脱敏预览。
预览对 gzip/deflate 有界解压，其他编码明确提示，下载仍保留原始编码字节。

列表增加方法、状态码/状态类别及正文预览搜索。SQLite 支持 FTS5 trigram 时使用全文索引，
不可用时回退到预览字面量匹配；不会搜索尚未保存或脱敏时省略的正文。
已有记录仍可查询，不会重新访问目标来补齐原文。

Agent 可通过 `traffic_search` 查轻量索引、`traffic_get` 读有界脱敏详情、
`traffic_body_read` 分页读取本会话原始正文，复用已有响应而不重复请求目标。
工具不能通过参数改写可信会话工作区；执行身份通过本地代理认证上下文绑定，
不会按目标地址猜测 Agent 或任务归属。

WS/WSS 保留握手、子协议和双向原始帧，未实现应用代理中的逐消息解码界面。
长连接、SSE 和 WebSocket 在连接结束后形成记录，代理列表不是实时帧监视器。
需要分析离线协议字段与 TCP/UDP 流时，打开对应的 PCAP 附件预览。

### 代理接口

下列接口沿用控制台认证，配置和下载响应禁用缓存：

- `GET /api/sessions/{session_id}/traffic/proxy`：代理状态，不返回口令。
- `POST /api/sessions/{session_id}/traffic/proxy`：启用，可传 JSON `upstream`。
- `DELETE /api/sessions/{session_id}/traffic/proxy`：停止并保留证据。
- `GET /api/sessions/{session_id}/traffic/proxy/environment`：显式读取含凭据的手动接入环境。
- `GET /api/sessions/{session_id}/traffic/proxy/ca`：下载公有 CA 证书包。
- `GET /api/sessions/{session_id}/traffic/{record_id}/original?direction=response`：下载原文，
  `direction` 可为 `request`、`response` 或 `metadata`。

应用交互列表另支持 `method`、`status`（如 `200` 或 `4xx`）、`body`（预览字面量）。

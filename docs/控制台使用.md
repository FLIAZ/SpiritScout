# 控制台使用

本文介绍当前控制台的任务、资产和运行观察入口。安装与模型配置见
[README](../README.md#配置模型并开始任务)，功能变化见 [更新日志](../CHANGELOG.md)。

## 页面与会话阅读

左侧功能菜单按工作区、智能体能力、连接与数据分组，会话列表与功能菜单可以分别收起。
会话内通过功能导航查看任务进展、资产与情报、文件与报告、后台任务和流量。

会话阅读区支持搜索已加载记录和按内容分类的阅读目录。长历史按需加载，目录和搜索范围
以当前已加载内容为准；它们不会额外请求模型，也不能代替对完整历史证据的查询。
查看较早记录时，流式输出和刷新会保留阅读位置；可通过回到最新位置继续跟随输出。

## 新建任务

### CTF 题目资料

选择 CTF 后，题型、题目名称、地址、描述、提示和多答案设置显示在同一张资料卡中。
题型可多选，也可填写其他方向；留空时由 Agent 判断，选择题型不会固定后续解法。
上方任务输入框可填写额外要求、已有思路和注意事项，附件通过底部上传或拖放加入。
默认取得一个答案即完成，多答案题目可切换为解出全部答案后结束。

智能体竞赛的「生成 WP」是独立选项，默认不在结束后生成 WP；需要解题报告时在创建会话时开启。
轻量部署的可用模式与工具以其配置为准。

### 资产收集与 SRC 任务

1. 从左侧进入「资产收集」，选择项目、收集模型与主动请求出口。模型配置沿用「模型」页，收集选模独立于任务会话。
2. 新建收集任务，填写目标资产或组织主体、本批次排除项及收集要求。AI 结合资料选择命令、工具或收集引擎。
3. 在页面查看实时输出、Token 与端点缓存计量；可暂停下一步、继续或停止，运行失败时保留错误和已有结果。
4. 结果按批次保存在项目资产库，可筛选 HTTP 响应、DNS 解析、待验证或验证失败的候选，分页查看或导出 CSV。
5. 完成收集后，点击「选择资产开始 SRC 会话」，勾选本次目标。也可在新建 SRC 会话时从当前项目资产库选择已完成批次。
6. 创建 SRC 会话时选择边缘资产优先、核心资产优先或均衡推进，以及本次会话出口。所选资产清单以 CSV 附件带入，模型根据现场收益调整测试顺序。

资产收集、第三方情报和历史发现都不自动授予主动测试权限；本次会话以明确选择的目标和用户提供的规则为准。
收集批次与测试会话各自保存出口配置，修改代理池不会替换运行中会话的固定出口。
配置与覆盖边界见 [SRC 发现与代理](SRC发现与代理.md)。

## 子 Agent 独立对话

SRC 和普通 CTF 会话可展开右侧「实况」栏，选择可用子 Agent 开始旁路对话。
无需等待该角色获得任务；「引用任务」默认为独立对话，只有主动选择任务时才带入该任务的历史快照。

旁路拥有独立消息历史、草稿和执行状态，发送消息不会暂停或改写父会话正在进行的任务。
需要更大的阅读区域或处理待答问题、审批时，可展开旁路会话。它沿用父会话的模式和授权范围，
SRC 危险操作仍按会话审批；历史快照不构成新授权。智能体竞赛不提供该人工对话入口。

## 文件、报告与后台存档

「文件与报告」集中查看附件、脚本、工具原文、专项任务报告和正式报告。
专项报告保留交接摘要、已知与未知事项、证据引用；Agent 自评和工具命中不等同于独立复测确认。
文件可按已有版本预览和下载，缺失或尚未生成的内容会显示实际状态。

「后台任务」集中展示运行中与已结束的 Shell 作业。选择一项可查看原始命令、分页读取和搜索
stdout/stderr，并复制或下载存档。停止任务与清理存档是不同操作，存档不完整也不等于命令执行失败。
详见 [定时任务与后台 Shell](定时任务与后台Shell.md)。

## 流量记录与出口

流量页用于查询任务产生的 HTTP/HTTPS、DNS、TCP 与会话网关交互，支持筛选、分页、请求响应详情和原文读取。
页面不再提供独立的代理采集开关、CA 配置或上游出口输入；SRC 出口在创建会话时统一选择，
会话页显示所保存方案与开工时核实的出口信息。

已有记录不会因为刷新页面重新请求目标。离线 PCAP/PCAPNG 在附件查看器中分析，
协议和原文保存边界见 [流量记录](流量记录.md)。

## 仪表盘与系统资源

仪表盘按北京时间展示所选时段的 Token、调用、费用估算、输入缓存命中率与确认成果，
可按模型、角色或会话查看分组，并筛选会话明细。金额是运行记录中的估算，实际账单以供应商为准。
未提供计价或缓存用量的记录显示为未知，不当作零费用或零命中。

进入仪表盘会先展示页面结构与读取状态，真实统计返回后填入数值。刷新复用未变化的历史快照，
新增用量和日志会使相应快照失效；时间窗口会随当前时间重新计算。

系统资源面板展示 Linux 主机及 SpiritScout 进程树的 CPU 和内存使用，数据定期采样。
首次 CPU 采样、无法读取或部分进程不可见时会说明缺口；这些数据仅供控制台观察，不进入模型上下文。

## 界面语言与反馈

简体中文和 English 使用本地语言包，可在侧栏或登录页切换。界面文案会翻译，
项目名称、会话内容、模型自定义名称、附件和证据原文保持原样。
动效与主题设置沿用全局偏好；流式输出、轮询与列表刷新不会重复播放整页入场动画。
